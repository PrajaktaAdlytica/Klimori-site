# Klimori

Klimori is a premium narrative website concept for a commercial-building energy intelligence platform. The site connects schedules, occupancy, weather, tariffs, and maintenance into one operating story across Monitor, Optimize, and Peak.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Stack

- React 19 and React Router
- Vite
- GSAP and ScrollTrigger
- Lucide and React Icons

The request and sign-in flows are intentionally local preview experiences; they do not transmit information or authenticate users.
